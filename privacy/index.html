1. はじめに

本ポリシーは、iPhone 向けアプリ「釣果ログ」（以下、本アプリ）における情報の取り扱いについて説明するものです。本アプリの利用開始をもって、本ポリシーに同意いただいたものとみなします。

本ポリシーはアプリのバージョン v1 の実装内容に基づいています。実装と異なる内容が生じた場合は、実装の内容を優先します。

2. 取り扱う情報

本アプリが利用する情報は以下のとおりです。

情報の種類 内容と利用目的
写真と Exif ユーザーが選択した写真から撮影日時・位置情報（Exif）を読み取り、釣果の日時・場所の初期値に使用します。写真の原本はサーバーへ送信しません。
位置情報 釣果の記録位置を地図上で確認・修正するために使います。また、釣果場所に対応する海況データ（底質・魚礁・潮汐）を参照する際に、位置情報を 0.2° × 0.2° のタイル単位に丸めて使用します。生の緯度経度をサーバーへ送信することはありません。
ユーザー入力情報 魚種・水深（魚探の実測値）・メモ・タックル情報などをユーザーが手動で入力します。これらは端末内にのみ保存されます。
端末内データ アプリの動作に必要なデータ（SwiftData による SQLite）は端末内に保存されます。外部には送信されません。

3. 情報の保存場所

  • 釣果の原本は端末内のデータベース（SQLite）に保存されます。
  • iCloud 同期は任意です。お使いの iCloud アカウント（プライベートデータベース）に同期できますが、無効にしても全機能が動作します。
  • 本アプリのサーバー（Cloudflare Workers）は釣果データを受け取りません。
  • 全件を JSON 形式でエクスポートできます（設定画面から操作できます）。

4. 外部サービスへの通信

本アプリは、海底地形・底質・魚礁・潮汐のデータを取得するため、インターネットへの接続を行います。通信の仕組みは以下のとおりです。

通信先 目的と内容
Cloudflare Workers
（fishing-log-api.kouhei1.workers.dev）		 海しるAPI のプロキシ。釣果場所を 0.2° タイル単位に丸めた範囲座標を送信し、GeoJSON 形式の海況データを受け取ります。個人情報・釣果データは含みません。
海しるAPI（海上保安庁） Cloudflare Workers 経由でアクセスします。iPhone から直接呼び出すことはありません。
Open-Meteo API 天気・風況データの取得に使用します。釣果場所の概算座標のみを送信します。

通信に失敗した場合も、釣果の保存・閲覧・分析はオフラインで動作し続けます。

5. 第三者提供・広告・解析

本アプリは現在、以下を行っていません。

  • 広告SDK の組み込み
  • 解析SDK・クラッシュレポートSDK の組み込み
  • 釣果データや個人情報の第三者への販売・提供

上記は v1 実装時点の事実です。将来の機能追加により変更が生じる場合は、本ポリシーを更新して通知します。

6. アカウントとログイン

本アプリにアカウント登録機能はありません。メールアドレスや個人情報の登録なしにすべての機能をお使いいただけます。

7. 権限の利用目的

本アプリが要求するシステム権限とその目的は以下のとおりです。

権限 なぜ必要か
写真ライブラリ 釣果を記録する際に写真を選択するために必要です。撮影日時・位置情報（Exif）を記録の初期値に使用します。写真データはサーバーへ送信しません。
カメラ その場で写真を撮影して即時記録するために必要です。撮影した写真は端末内にのみ保存されます。
位置情報（使用中のみ） 釣果場所を地図上に正確に記録するために必要です。0.2° タイルに丸めた座標のみを海況データ取得に使用します。

8. データのエクスポートと削除

  • エクスポート：設定画面の「データのエクスポート」から、全釣果データを JSON 形式でファイルに書き出せます。
  • インポート：エクスポートした JSON を別の端末に取り込むことで、記録を移行できます。
  • 削除：個別の釣果はスワイプで削除できます。全件削除は設定画面から操作できます。アプリをアンインストールすると、端末内のデータもすべて削除されます（iCloud 同期が有効の場合は iCloud 側も別途削除が必要です）。

9. 子どものプライバシー

本アプリの年齢制限は 4+ です。個人情報の入力を要求しない設計のため、年齢に関わらずご利用いただけます。

10. データの出典と免責

このサービスは、海しるAPIを利用して取得した情報をもとに作成しているが、サービスの内容は海上保安庁によって保証されたものではない

出典：海洋状況表示システム（https://www.msil.go.jp/）

本アプリは、航海・安全・漁業その他の専門的判断には使用できません。

11. 本ポリシーの変更

本ポリシーを変更する場合は、このページの最終更新日を更新します。重要な変更がある場合は、アプリ内でも通知します。

最新のポリシーは常にこのページでご確認いただけます。
