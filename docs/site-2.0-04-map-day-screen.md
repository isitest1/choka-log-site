# 指示書 4：トップの写真用の「1 日の航跡の地図」の画面を撮る（iPhone 版のリポジトリ、手元の Mac のセッション）

サイト（https://chokalog.margheritaworks.com/）のトップの、いちばん上に並ぶ 3 枚の画面の写真のうち、左の 1 枚に使う画面を撮ってください。
作業するのは、iPhone 版のリポジトリ（isitest1/fishing-log）の `release/2.0` です。

## 1. 撮る画面

**地図のタブに、2026/10/3（土）の 1 日の航跡が、出港から流し、帰港までまるごと入っている画面**です。

- データ：今の `docs/site-2.0-assets/` と同じ、デバッグ版のデモのデータ（`DemoWelcomeSeeder`）。2026/10/3 の釣行（06:12 に三崎港を出港、13:30 に帰港。釣果は 07:18 アジ・08:47 マダイ・11:21 カワハギ）。
- 状態：その釣行を終えた直後で、終えた航跡がそのまま地図に出ている状態にしてください（修正 5-4 の「終了した航跡は地図に残る」）。左上は「釣行を開始」のボタンの状態で構いません。
- 範囲：
  - 1 日の航跡と 3 匹の釣果が、すべて画面に入る範囲にしてください。
  - 航跡と釣果の範囲は、北 35.139203・南 35.101774・西 139.582024・東 139.637918 です（`track-day.json` の `bounds`）。
  - 北を上にして、回さないでください。
  - 港（三崎港）と城ヶ島の形が、画面の上のほうに見えるようにしてください。
- 線：移動中は細かい点線、釣り中は実線で、出港から帰港までが 1 本につながって見えること。
- 魚：アジ・マダイ・カワハギの赤い点と名前が出ていること（「ほか」でまとめられていないこと）。
- **座標の窓（右上）に数字が出ていること**：
  - 位置情報の許可を「使用中のみ許可」にし、シミュレーターの位置を三崎港（緯度 35.139188・経度 139.620464）にしてください。
  - N・E・十字（十字までの距離と方位）に数字が出る状態で撮ってください。
  - 止まっている所なので、SOG は 0.0、COG は「—」で構いません。
  - 前の `map-zoom` は、座標の窓が「—」だったので使えませんでした。
- 十字：地図の中心の十字は、航跡の上に重なっても構いません。
- 時計：13:35 前後。
- 表示：地図は明るい表示です。端末の枠は入れないでください。
- 機種：今の素材と同じシミュレーター iPhone 17 Pro（402×874pt、3 倍）。

## 2. 書き出し

- `docs/site-2.0-assets/screens/map-day.png`（元の大きさ、1206×2622px）
- `docs/site-2.0-assets/screens/map-day.webp`（幅 750px、200KB 以下。ほかの WebP と同じ作り方）

`docs/site-2.0-assets/README.md` の `screens/` の表に、`map-day` の行を足してください（画面・時計・中身）。
撮り方を `scripts/site-assets.sh` に足せるなら、`ONLY="map-day"` で撮り直せるようにしてください。

## 3. 決まり

- アプリのコード（`FishingLog/` の下）は、撮影のための一時的な変更を除いて変えないでください。撮影のための変更は、コミットしないでください。
- 素材は `release/2.0` の `docs/site-2.0-assets/` にコミットして、プッシュしてください。
- 終わったら、`map-day.webp` の画面のスクリーンショットと、座標の窓に出ている値を報告してください。

## 4. この後（サイトのセッションで行うこと）

サイトのリポジトリの `site-2.0` で、`assets/img/2.0/map-day.webp` に写します。トップの左の写真（今は仮で `recording-map`）と、スマホの幅で横に送る写真の 1 枚目を、`map-day` に差し替えます。
